# carrion-simplebot
A simple bot interface for carrion.chat.

Requires [lua https](https://github.com/love2d/lua-https), [carrion crypta](https://github.com/myonmyuu/carrion-crypta-lua/tree/master) and [lua sse](https://github.com/myonmyuu/lua-sse-rs).

Example bot [here](https://github.com/myonmyuu/carrion-fmk-bot)
